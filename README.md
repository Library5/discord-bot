# Discord Bot - Vortex 🤖

بوت ديسكورد احترافي يتضمن أوامر إدارية شاملة، نظام مكافحة السبام، إدارة الأدوار، والعديد من الميزات الاحترافية.

## ✨ الميزات الرئيسية

### 🛡️ **أوامر الإدارة**
- `/kick` - طرد عضو من السيرفر
- `/ban` - حظر عضو من السيرفر
- `/mute` - إسكات عضو
- `/unmute` - إلغاء إسكات عضو
- `/clear` - حذف عدد معين من الرسائل
- `/warn` - تحذير عضو

### 🎉 **نظام الجيفاوي**
- `/giveaway` - إنشاء جائزة جديدة
- `/endgiveaway` - إنهاء جائزة يدوياً
- 🎉 اضغط على الإيموجي للمشاركة

### 🛠️ **أوامر الإشراف الاحترافية**
- `/slowmode` - تفعيل الوضع البطيء (منع السبام)
- `/lock` - قفل القناة
- `/unlock` - فتح القناة
- `/announce` - نشر إعلان رسمي
- `/role` - إضافة أو إزالة أدوار
- `/channelinfo` - معلومات عن القناة
- `/setlogchannel` - تحديد قناة السجلات

### 📊 **أوامر المعلومات**
- `/serverinfo` - معلومات عن السيرفر
- `/userinfo` - معلومات عن المستخدم
- `/botinfo` - معلومات عن البوت
- `/ping` - اختبار استجابة البوت
- `/getstatus` - الحصول على الستاتيوس الحالي

### 👑 **أوامر صاحب البوت**
- `/status` - تغيير ستاتيوس البوت
- `/guilds` - عرض قائمة السيرفرات
- `/leave` - خروج البوت من سيرفر
- `!sync` - مزامنة أوامر سلاش

### ⚠️ **نظام مكافحة السبام الذكي**
- 🤖 كشف تلقائي للسبام (5 رسائل في 5 ثواني)
- 💬 تنبيه العضو عبر رسالة خاصة
- 📝 تسجيل في قناة السجل (اختيارية)
- 🚨 تحذيرات متدرجة للمخالفين

## 📦 التثبيت

### 1️⃣ استنساخ المشروع
```bash
git clone https://github.com/Library5/discord-bot.git
cd discord-bot
```

### 2️⃣ تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 3️⃣ إعداد متغيرات البيئة
```bash
cp .env.example .env
```

عدّل ملف `.env` وأضف توكن البوت:
```
DISCORD_TOKEN=your_bot_token_here
BOT_PREFIX=!
ADMIN_ROLE=Admin
```

### 4️⃣ تشغيل البوت
```bash
python main.py
```

## 🚀 الاستخدام السريع

### إنشاء جائزة
```
/giveaway duration:3600 winners:2 prize:Nitro Classic
```

### تحذير عضو
```
/warn member:@user reason:سلوك سيء
```

### تفعيل الوضع البطيء
```
/slowmode seconds:5
```

### تحديد قناة السجل
```
/setlogchannel channel:#logs
```

### تغيير ستاتيوس البوت
```
/status activity:Playing Vortex 🎮
```

### عرض السيرفرات
```
/guilds
```

## 📋 متطلبات السيرفر

- 🎖️ **رول Admin** - لاستخدام الأوامر الإدارية
- 🔑 **صلاحيات الإدارة** للبوت
- ✅ **تفعيل Message Content Intent** في Developer Portal

## ⚙️ إعدادات الحماية من السبام

البوت يكتشف تلقائياً:
- 5 رسائل في 5 ثوانٍ = تنبيه
- يتم إرسال رسالة خاصة للعضو
- يمكن تحديد قناة لتسجيل التنبيهات

```python
# في cogs/antispam.py
self.spam_threshold = 5      # عدد الرسائل
self.spam_time_window = 5    # عدد الثواني
```
